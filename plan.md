## Implementation

Use the installed React/TypeScript/Vite static starter. No server, database, personal integrations, login, paid API or background automation is required for this hypothesis test. Keep demo data and personal data separate in versioned browser-local storage. Export JSON losslessly and CSV core fields; import is additive with validation and dependency remapping, not silently destructive. Browser storage is per device/origin and not a backup.

Pure domain modules own dates, workflow derivation, explainable relevance, sample scenarios, quick parsing, completion/recurrence and import/export. Ready tasks, due follow-ups and clarification/review actions can be recommended, but incomplete dependencies prevent a start. The attention set is capped at five, preserves a due-review/important-undated slot where possible, and always exposes all approaching/passed commitments outside the cap. Explicit user filters never erase the independent commitment summary.

Home provides a lead task with next action and reason, up to four alternatives, context and available-time filters, landscape directory and quiet inventory links. All work supports search, area/state filters and pagination. Review surfaces due reviews and missing next actions. Waiting includes blocked work with reasons and dependency links. Progress exposes completion history. Task detail edits workflow, next action, notes, local calendar dates, checklist, recurrence and prerequisites. Completed work leaves recommendations. A snapshot undo reverses the last task mutation.

Focus stores the intended task, an explicit next action and a short timer across reloads. Pause is valid. An opt-in focus checkpoint and an 'I'm drifting' restart flow offer a two-minute entry step, a break or a plan change without monitoring other apps or inferring mental state. Do not equate timer expiry with completion.

Mandatory voice: browser speech recognition begins only on explicit request, recognises into a reviewable draft, shows listening/errors and supports abort. Read-aloud of summary/task is explicit with stop. Limited voice commands may propose focus completion/deferral, never perform them without confirmation. Feature-detect and disclose browser-vendor processing and possible need for connectivity/full Chrome on Android. No claimed universal WebView/offline voice support.

Demo lab supports few/50/200/500 jobs, deadlines, overdue, undated and nothing-urgent datasets, and replaces only sample data. Personal work begins empty. PWA uses application-owned manifest/icons and production service worker shell caching. No exact closed-app reminders or automatic cloud sync. Runtime relevance updates while open and on reopening.

## Design

Three sampled alternative visual styles: quiet editorial stationery (p=0.034), dark instrument-panel minimalism (p=0.068), botanical field notebook (p=0.060). Choose quiet editorial stationery.

**Design Movement:** contemporary editorial minimalism with the restraint of Swiss information design and warm paper-like surfaces.

**Core Principles:** action before inventory; meaningful hierarchy rather than a card mosaic; stable structure and text-coded states; ample breathing room with precise alignment.

**Color Philosophy:** warm ivory keeps the interface human, deep pine supplies a confident anchor, soft sage marks actionable work, and muted amber identifies real commitments without blanket red alarms. Text contrast takes precedence over pastel styling.

**Layout Paradigm:** a slim left navigation rail, an editorial attention column and a quieter right landscape margin. The lead action is a broad reading surface; alternatives are rows, not equal competing tiles. On phones the primary action comes first, the landscape follows and navigation becomes a compact accessible bottom bar.

**Signature Elements:** offset concentric incomplete-circle brand mark representing a selected focus inside a larger held inventory; hairline separators; tiny typographic status labels paired with icons and words.

**Interaction Philosophy:** explicit start, review and defer choices, one detail dialog rather than deep navigation, undo after mutations, no surprise action from a voice transcript.

**Animation:** subtle 150–180ms opacity/translate transitions only for deliberate openings and hover changes; no pulsing urgency or automatic reordering animation; respect prefers-reduced-motion entirely.

**Typography System:** Georgia or a bundled serif for large expressive headings and the slightly tightened wordmark; system sans (Inter-like system stack) for dense interactive text, 15–16px base and clear 12–13px metadata. No network font dependency is required offline.

**Brand Essence:** a calm attention layer for people carrying many responsibilities, keeping the whole picture without making it all today's problem. Personality: grounded, considerate, clear.

**Brand Voice:** practical and non-judgmental. Examples: 'A few things worth your attention.' and 'The rest is held here. It is not all for today.'

**Wordmark & Logo:** lower-case serif steadier with an offset open-orbit symbol, not a generic text-only logo.

**Signature Brand Color:** deep pine #24483E.
